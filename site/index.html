About TouchlineAI Prototype
What is Real:

Fully interactive client-side state machine; individual coach review requirement; dynamic clip counts and reel generation; publication preflight revalidation (FR-21); batch validation gates (FR-17, FR-18); decision audit ledger (FR-10); approval invalidation on modification (FR-20); delivery manifest and idempotency checks (FR-22); failed delivery retry (FR-23); responsive mobile layout (375px+).

What is Simulated:

AI moment detection engine (deterministic mock data); synthetic jersey frame rendering; SMS/Email delivery dispatcher. No backend, no API keys, and system fonts only.
